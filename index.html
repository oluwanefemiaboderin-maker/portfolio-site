About

How I work

  1. Understand

    Talk to users and stakeholders to learn the problem before drawing anything.

  2. Define

    Turn findings into clear goals, user flows and a simple structure.

  3. Design

    Sketch, wireframe and prototype in Figma, then refine the visual interface.

  4. Build and test

    Hand over clean specs or code the front end, then test with real people.
